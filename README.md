# Hello GitHub
Learning Git and Actions
Testing branch protection
Testing code ownership

## Contribution Workflow

1. Synchronize your local main branch.
2. Create a feature branch from main.
3. Make and test your changes locally.
4. Stage and commit your changes.
5. Push your feature branch to GitHub.
6. Open a pull request targeting main.
7. Obtain the required review approval.
8. Ensure all required status checks pass.
9. Merge the approved pull request.

## Repository Security

- Direct pushes to main are restricted.
- Required code reviews must be completed.
- GitHub Actions must be pinned to full-length commit SHAs.
- Secrets must never be committed to the repository.
