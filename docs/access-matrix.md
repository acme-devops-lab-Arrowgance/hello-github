# Repository Access Matrix

Organization: acme-devops-lab-Arrowgance

## Team Permissions

| Team | hello-github | infrastructure-demo |
|---|---|---|
| developers | Write | Read |
| reviewers | Write | Read |
| platform-admins | Maintain | Admin |

## Responsibilities

### developers
Develop application code and submit pull requests.

### reviewers
Review proposed changes and provide approvals.

### platform-admins
Maintain repository configurations and administer
infrastructure repositore access.

## Access Control Notes

- Repository permissions are assigned through GitHub teams.
- Organization owners retain administrative access.
- Users belonging to multiple teams receive their highest
  applicable permission.
